# Мои заметки. Неделя 1

## PATH
Внутренняя переменная системы. Нужна для быстрого доступа к каким либо данным (программам)

## venv
Это виртуальное окружение. Нужно, чтобы пакеты не конфликтовали.

## Коммит
Сохранение файловой структуры. Хорошая аналогия для запоминания - концепция фотграфии: файловая структура на ПК - окружающий мир, git add - команда "Приготовились!", git commit - фотография на ПК, git push - отправка фото на облако.

## .gitignore
Файл, в котором записано что git add . не будет брать.

## assert
Команда проверки. Если True - тест проходит, если False - тест падает.

## FAILURES
Отчет об ошибках. Если тест упал какой-то, FAILURES показывает какой именно и что не сошлось.
